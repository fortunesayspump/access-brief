## Proposed title
Access Brief — access information without an accessibility score

## Proposed description
Access Brief turns one evidence-linked venue record into a web guide, a pre-visit email and a large-print reading copy. It keeps published statements separate from questions that still need confirmation. No universal access score, no invented measurements and no implied on-site inspection.

The example uses real Smithsonian National Museum of Natural History information with a visible review date. A second blank record shows how the templates handle missing information. Hyper Elements powers three genuinely different output structures, a shared theme and reusable evidence components. HTML remains primary; the PDF is not claimed to be PDF/UA certified. No social image is produced because freezing access information into an image would defeat the reading and resizing use case.

Build, typecheck and 19 tests pass. Desktop and 390px-width layouts and the reading-size control were reviewed. The README documents source provenance and remaining accessibility-testing limits.
